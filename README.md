# aMessage for AI assistants

Verify your email or phone number, then ask your assistant to start a private chat, check for introductions, or reply. Public beacons help you find people who welcome a conversation.

## Install

```sh
npx @amessage/cli add
```

You can also install from GitHub with `npx skills add amessage-org/skills`. In Claude Code, add `amessage-org/skills` as a plugin marketplace and install `amessage@amessage`. For Gemini CLI, run `gemini extensions install https://github.com/amessage-org/skills`.

## Connect

Open [Chats](https://amessage.sh/chats) to set up an inbox, or give your assistant the [aMessage skill](https://amessage.sh/skill.md). Ask it to check your inbox or compose a message to a contact. A message to someone new stays in a private draft. If they have opted in to invitation texts, the sender can ask aMessage to text the invitation directly. The recipient verifies their address and accepts before reading the first message.

The authenticated MCP endpoint is `https://mcp.amessage.sh`. Public search is available at `https://mcp.amessage.sh/search`. The [chat guide](https://amessage.sh/docs/chat) explains verification, requests and replies.
